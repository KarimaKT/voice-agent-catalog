# Copilot Studio sample agents

This folder contains tenant-neutral Copilot Studio assets. It intentionally
contains no customer tenant IDs, environment URLs, recipient addresses,
connection identifiers, or credentials.

## Importable sample solution

Import this ZIP through **Solutions** in Power Apps or Copilot Studio:

```text
packages/pat-manager-handoff-solution.zip
```

[Download the Pat manager-handoff solution ZIP](packages/pat-manager-handoff-solution.zip).

The ZIP is generated by Power Platform CLI's `pac copilot pack` command and is
a real Power Platform solution package, not an arbitrary source archive.

See the [installer guide](../docs/installer/README.md#import-the-sample-agent)
for destination-environment steps.

## What the package contains

- **Pat Manager Handoff Sample**
- Four-topic manager-handoff instructions
- A concise conversation-start topic
- Standard Copilot Studio system topics
- Microsoft integrated authentication settings
- Generative orchestration settings
- Web browsing, file analysis, semantic search, and general model knowledge
  disabled because the interview should use only the user's answers

The package does **not** include:

- an authorized Outlook connection;
- a destination recipient;
- a tenant or environment binding;
- the SharePoint catalog;
- Azure or Teams resources; or
- credentials of any kind.

Power Platform solution packages cannot carry destination connector
credentials. This separation is required for a safe reusable sample.

## Required post-import configuration

After import:

1. Open **Pat Manager Handoff Sample**.
2. Add **Office 365 Outlook - Send an email (V2)**.
3. Configure the recipient and connection policy by following
   [outlook-action.md](outlook-action.md).
4. Verify the action is available to generative orchestration.
5. Test one vague answer and one complete interview.
6. Confirm exactly one formatted HTML email is sent.
7. Publish the agent.
8. Share it with intended runtime users.
9. Store its environment ID and schema name only in an ignored local
   deployment file.

## Editable source

The packable source is:

```text
sample-agent/solution-source/
```

It contains `agent.mcs.yml`, `settings.mcs.yml`, and standard topic YAML files.
Edit and validate the source before rebuilding the ZIP.

`agent-instructions.txt` remains a convenient copy/paste version for makers who
create the agent manually. `outlook-action.md` documents the destination-owned
connector action.

## Rebuild the solution ZIP

Install or update Power Platform CLI, then run:

```powershell
.\scripts\package-sample-agent.ps1
```

The script scans the source for obvious tenant-specific values, runs
`pac copilot pack`, validates the generated package by unpacking it, and
replaces `packages/pat-manager-handoff-solution.zip`.

Do not rebuild the public package from a customer-connected clone. Customer
clones can contain recipient addresses and connection-reference names.

## Create an agent manually

If solution import is unavailable:

1. Create a standard Copilot Studio agent.
2. Select Microsoft authentication.
3. Paste `agent-instructions.txt` into the agent instructions.
4. Add and configure the Outlook action.
5. Test all four topics, a vague answer, failure behavior, and exactly one email.
6. Publish and share the agent.
